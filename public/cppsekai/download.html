跑起来需要什么

系统要求

  • Android 4.4 及以上，或 x86_64 Linux（glibc 2.31+）
  • 支持 OpenGL 3.3 的显卡与驱动
  • 至少 1.2GHz CPU
  • 至少 512MB RAM

关于谱面

  • 仓库不自带谱面与音频，装好后列表是空的属于正常
  • 用 chartdl 下载，或自己往 charts/ 里放
  • 放完在选曲界面点「重扫」（桌面端按 F5）

对于没有独显的机器

游戏本体要 OpenGL 3.3。要是驱动太老、只有 Mesa 的软件渲染，或者启动时闪一句 Failed to initialize OpenGL loader! 就没了，才需要走下面这条路。

极端情况才用

这会导致画面全部丢给 CPU 硬算。 仅适用于没独显的旧一体机和云桌面能正常启动的机器，请直接用上面的包。

  • 慢 2 到 3 倍。核心数少的机器更差。
  • 进得去不等于打得动。判定窗口只有几十毫秒，再叠上云桌面本身的网络和编解码延迟。
  • Linux 怎么开。启动时带上环境变量 LIBGL_ALWAYS_SOFTWARE=1 ./cppsekai；先装个 mesa-utils，用 glxinfo | grep "OpenGL version" 能确认当前是不是软渲染。
  • Android 怎么开。没有这个开关 —— 系统驱动给不出 GLES 3.0 的话，装上也进不去，换台设备吧。

常见问题

为什么打开之后一首歌都没有？

版权原因，仓库里不带谱面和音频。打开附带的 chartdl 把想打的曲子下下来，列表就有了。

手柄能打歌吗？

不能，手柄只管菜单：方向键或左摇杆选歌、换难度，A / START / Y 负责开始、开设置、重扫，B / BACK 退回。

键盘打不出左右 flick？

一个键没有方向，键盘只能发向上 flick；左右方向必须用鼠标或触摸甩出来。触屏上垂直滑动不好触发的话，可以在 设置 → 判定 里打开「Flick 视作 Tap」。

长条什么时候会断？

尾判是松手判定：结束前在容错窗口内松手，按距离给 Perfect / Great / Good；一直按到底同样是 Perfect。只有明显提前松手才算断连，窗口大小在 设置 → 判定 → 长条容错 里调。

点开没反应 / 提示缺某个库？

Linux 下先在终端里跑一遍 ./cppsekai，缺什么库终端会直接报出来，ldd ./cppsekai 也能看到没解析到的依赖；日志写在当前工作目录的 cppsekai.log，出问题先看它最后几行。Android 上的崩溃日志在同目录的 cppsekai.log。

怎么和同学一起打？

设置 → 系统 → 多人游玩。勾上之后重启，再多开几个窗口就会出现新座位。有几个人就开几个，同机自动连上，不用配网络。

支持哪些平台？

官方只做 Android（4.4+） 和 x86_64 Linux 两端：触控、媒体会话和共享内存都用的是这两个平台的原生接口。Windows / macOS 暂时没有，想看网页版可以去上游 sekai-mmw-preview-web。

它会联网吗？会上传什么东西吗？

游戏本体没有任何网络代码。只有 chartdl 下载谱面时会联网，也不上传任何东西。

启动一闪就没了 / 报 OpenGL 错误？

先看游戏目录下 cppsekai.log 的最后几行。如果有 Failed to initialize OpenGL loader!，说明这台机器没有可用的 3D 驱动，去上面「没有独显的机器」那一节。能正常启动的话，那段不用管。
